## Mengapa lahan gambut mudah terbakar saat kemarau?

Menurut Kementerian Lingkungan Hidup dan Kehutanan (KLHK), tanah gambut sifatnya menyerupai spons. Pada kondisi normal ia menyerap dan menahan air sebanyak mungkin, tetapi pada musim kemarau lahan ini mengering sampai kedalaman tertentu dan menjadi mudah terbakar.

## Mengapa kebakaran gambut sulit dipadamkan?

KLHK menyebut gambut mengandung bahan bakar berupa sisa tumbuhan sampai di bawah permukaan tanah. Karena itu api menjalar di bawah permukaan secara lambat dan sulit dipantau pergerakannya. Kebakaran di lahan gambut sulit dipadamkan sehingga bisa berlangsung berhari-hari. Menurut KLHK, pemadaman darat perlu didukung pemadaman udara (water bombing) agar api benar-benar padam.

## Mengapa kebakaran gambut menghasilkan asap tebal?

KLHK menjelaskan bahwa api yang menjalar di bawah permukaan gambut sulit dideteksi dan menimbulkan asap tebal. Karena apinya menjalar di bawah permukaan tanah, ia tidak selalu terlihat dari atas.

## Mengapa titik api di lahan gambut mendapat perhatian khusus di SiagaApi?

Karena kebakaran gambut sulit dideteksi dan dipadamkan serta menimbulkan asap tebal (lihat penjelasan KLHK), SiagaApi menandai titik api yang jatuh di lahan gambut dengan warna ungu dan menyediakan filter khusus untuk menampilkannya saja. Ini membantu petugas dan warga melihat mana titik yang berada di lahan yang paling sulit ditangani.
